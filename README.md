## Spotlight Project: ToolSnapy

> Privacy first online tools that run entirely in your browser. No tracking, no cloud uploads, no data collection.

ToolSnapy is a full stack suite of fast, free, privacy focused utilities. Files are processed locally using modern Web APIs, so user data never leaves the device. It bundles more than fifty tools across images, PDFs, text, calculators, and developer utilities, plus an instant share feature for text and files that auto deletes shared content after fifteen minutes.

```mermaid
flowchart TD
    U[User Browser] -->|local processing| T[ToolSnapy Frontend]
    T --> I[Image Tools]
    T --> P[PDF Tools]
    T --> D[Dev Utilities]
    T --> S[Instant Share]
    S -->|temporary, auto expiring| B[Share Backend]
    B -.->|deleted after 15 min| X[No Data Retained]

    style U fill:#0EA5E9,stroke:#0B1120,color:#ffffff
    style T fill:#7C3AED,stroke:#0B1120,color:#ffffff
    style S fill:#DB2777,stroke:#0B1120,color:#ffffff
    style B fill:#059669,stroke:#0B1120,color:#ffffff
    style X fill:#F59E0B,stroke:#0B1120,color:#0B1120
```

**Highlights**
- In browser image compression, background removal, format conversion, and OCR
- PDF merge, split, and conversion tools with no server side upload
- Developer utilities such as JSON formatter, hash generator, UUID, and Base64 tools
- Instant share with short codes and automatic expiry for privacy

`React` &nbsp; `TypeScript` &nbsp; `Node.js` &nbsp; `Web APIs` &nbsp; `Privacy First`
